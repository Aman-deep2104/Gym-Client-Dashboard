# Gym-Client-Dashboard
## 1. Project

**Gym Report Dashboard – Power BI**
An interactive Power BI dashboard developed to analyze gym memberships, clients, finances, expenses, revenue, and profit through a clear and user-friendly reporting interface.

## 2. Short Description

This project provides a comprehensive view of gym business performance, including **Silver, Gold, and Platinum memberships**, total clients, membership status, revenue, expenses, and profitability.
The dashboard helps understand client trends and financial performance to support data-driven business decisions.

## 3. Tech Stack

**Microsoft Power BI, Power Query, DAX, Data Cleaning & Transformation, and Data Visualization** were used to build the dashboard.
Interactive KPIs, charts, slicers, and filters were implemented to make the report dynamic and easy to analyze.

## 4. Data Source

The dataset and supporting project references were collected using **YouTube and Google** for learning and dashboard development purposes.
The data was cleaned, transformed, and prepared in Power BI before creating the final visualizations and analytical reports.

## 5. Features

* **Membership Analysis:** Analyzes **Silver, Gold, and Platinum** membership categories.
* **Client Analysis:** Displays total clients and provides insights into **active and expired memberships**.
* **Financial Analysis:** Tracks overall **revenue, expenses, and profit** to evaluate business performance.
* **Revenue & Expense Tracking:** Provides a clear comparison of income generated against business expenses.
* **Membership Insights:** Helps identify membership distribution and client status across different categories.
* **Interactive Dashboard:** Uses KPIs, charts, slicers, and filters to allow users to explore gym performance dynamically.
